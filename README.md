# 🧱 Exercícios de Java — Programação Orientada a Objetos

Repositório com 10 exercícios práticos de Java, cobrindo os primeiros passos da Programação Orientada a Objetos: classes, objetos, métodos, construtores e enum.

---

## 📌 Sobre

Os exercícios simulam cenários simples do dia a dia (cadastro de pessoas, produtos, contas, livros, cursos e celulares), praticando os conceitos de forma progressiva, com apoio de `class`, `new`, `this`, construtores, métodos com e sem retorno e `enum`.

---

## ▶️ Como executar

1. Clone o repositório e abra a pasta no IntelliJ IDEA.
2. Abra o `ExercicioNN` desejado.
3. Clique no botão verde ao lado do `main` para executar.
